A one-line roast of a smart fridge that refuses to open after midnight — written to `/output/entry.txt` by `main.py` (pure Python stdlib, deterministic, no network).

> My smart fridge locks itself at midnight like it's guarding state secrets — relax, the only classified material in there is leftover pizza and my poor decisions.

## Run it

```sh
python3 main.py
```
